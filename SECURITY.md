# Security policy

## Reporting a vulnerability

Please report security issues privately by e-mail to [nyxify@nyxon.tech](mailto:nyxify@nyxon.tech), not in a public
issue, a pull request or the WordPress.org support forum.

Include what you found, the plugin version, and the steps to reproduce it. Please don't include real customers'
data, license keys, bot tokens or admin PINs; if a report needs one, say so and we'll arrange a safe way to share it.

We reply within a few working days, keep you informed while we fix it, and credit you in the changelog if you wish.

## Supported versions

Fixes go into the latest release on [WordPress.org](https://wordpress.org/plugins/nyxify/); please update before
reporting.

## Scope

This repository is the WordPress plugin. Issues in the Nyxify service or the bots themselves are welcome at the same
address.
